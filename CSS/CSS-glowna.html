2. Model Pudełkowy (Box Model)

Każdy element w CSS jest traktowany jak prostokątne pudełko. Składa się z czterech warstw: content (zawartość), padding (wewnętrzny margines), border (obramowanie) oraz margin (zewnętrzny margines).
